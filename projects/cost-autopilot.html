03 / LLM infrastructure

LLM Cost Autopilot

A routing layer in front of several LLM providers. It scores each request’s complexity, sends it to the cheapest model that can handle it, and keeps checking that those choices were right.

The problem

Teams running LLMs at scale overspend by sending every request to their most expensive model.

What I built

  • Unified interface across OpenAI, Anthropic and local Ollama models, with a registry of prices, latency and quality tiers.
  • A scikit-learn complexity classifier trained on hand-labeled prompts maps requests to three tiers, with a YAML routing map that can change without code edits.
  • An async verifier re-runs a sample on a stronger model and scores agreement. Failures trigger automatic escalation and become new training examples for the classifier.
  • Every request is logged with tier, model, cost, latency and quality score, feeding a dashboard that compares actual spend against sending everything to the top model.
  • FastAPI service exposing a completions endpoint plus model, stats and routing-config endpoints.
