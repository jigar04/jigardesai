RAG Pipeline with Hybrid Search

A retrieval-augmented generation system over internal documentation that combines vector and keyword search, answers with verified citations, and says so when the documents don’t contain the answer.

The problem

Most RAG demos use one PDF and trust whatever the model says. Real documentation needs strong retrieval, honest uncertainty and proof that each claim is supported.

What I built

  • Multi-format ingestion (Markdown, text, HTML, PDF) with three switchable chunking strategies: fixed size, structure-aware, and semantic.
  • Dense retrieval in ChromaDB with OpenAI embeddings, BM25 keyword retrieval, and Reciprocal Rank Fusion with configurable weights, followed by a reranker.
  • Grounded generation with bracketed citations, plus an LLM-as-judge check that each citation supports its claim.
  • A composite confidence score and a structured “I don’t know” response when retrieval is weak.
  • A hand-written golden Q&A set and metrics for correctness, faithfulness, retrieval relevance and citation accuracy, used to compare chunking strategies and hybrid versus dense-only search.
  • FastAPI service and a dashboard to inspect retrieved chunks.
